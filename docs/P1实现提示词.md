- 主数据：`data/market/daily_price/{code}.parquet`（`code` 带市场前缀去点，如 `sh600000`）。
- 前端：`web/` 为**原生 JS + ECharts**（Datasets/Strategies/Tasks 三页，无构建）。
- `cron_task` 表已建但 **APScheduler 尚未实例化**（P0 只预留）。
- 硬约束持续有效：**不修改 `script/`**；主数据来自平台内建摄取。

## P1 目标
1. 前端**切换 Vue3（Vite）**，重构为 5 页：数据管理 / 个股数据 / 策略 / 任务 / 调度（**去掉覆盖度热力图与覆盖度统计**，数据管理页仅保留最新日期/滞后天数）。
2. 新增**个股数据查看**：选股器（代码+名称+行业）+ 日期区间 + **三图并列**分别展示「不复权 / 前复权 / 后复权」日K（ECharts 主图 + 成交量副图），免切换。
3. **定时调度落地**：APScheduler 实例化接入 `cron_task`，应用重启后从库恢复已启用任务；前端调度页增删改/启停/立即运行/下次运行时间。
4. 策略/回测**暂不深化**（沿用 P0 现状，只保证新前端下可运行查看）。

## 技术栈（硬约束）
- 前端：**Vue3 + Vite + vue-router + ECharts**（P1 起替代原生 JS；旧 `web/js/*.js` 平移到 Vue 组件后删除，git 历史可追）。
- 后端：Python 3.10+，FastAPI + Uvicorn，纯 REST API（不渲染页面）。
- 元数据库：SQLite + SQLAlchemy（P0 已建表，按需**新增 `stock` 表**，见下）。
- 调度：**APScheduler（BackgroundScheduler）**，本期真正实例化。
- 数据源：**baostock**（摄取已用；个股基础信息用 `query_stock_basic`）。
- 脚本执行：subprocess（复用 P0 任务执行路径）。
- 明确不引入：Celery / Redis / 登录鉴权 / 多进程调度；CORS 放行本机来源（127.0.0.1、localhost、Vite dev 端口如 5173、WebView2 本机资源）。

## P1 必须完成的模块
1. **前端 Vue3 迁移重构**
   - 用 Vite 在 `web/` 建立 Vue3 工程（`web/src`、`vite.config`、`web/dist` 构建产物由后端托管 + SPA fallback）。
   - 页面与路由：`/`(数据管理)、`/stocks`(个股数据)、`/strategies`(策略)、`/tasks`(任务)、`/cron`(调度)。顶部导航。
   - API 封装层（替代旧 `api.js`）、ECharts 封装、基础组件（列表/表单/状态标签/日志查看）。
   - 迁移 P0 三页（数据管理/策略/任务），保证后端既有接口可用；**数据管理页去掉覆盖度展示**。
   - 开发期与生产：`npm run dev` 联调（后端开放对应 CORS 端口），`npm run build` 产物由 FastAPI 静态托管 + 前端路由 fallback。
2. **个股数据查看**
   - 新增 `stock(code, name, industry)` 表（见方案 6.3）；提供**初始化任务**从 baostock 拉取 A 股基础信息入库（`code` 规范为 `sh600000` 去点格式），可在数据管理页手动触发或首次使用个股页时提示。
   - 新增后端只读接口：
     - `GET /api/stocks`：返回 `[{code, name, industry}]` 供选股器。
     - `GET /api/stocks/{code}/kline?from=YYYY-MM-DD&to=YYYY-MM-DD`：读 `data/market/daily_price/{code}.parquet`，按区间过滤，**列裁剪只读**，一次返回 `date` + 不下复权价(OHLCV)、前复权价(`qfq_open..qfq_close`) 与成交量、后复权价(`hfq_open..hfq_close`) 与成交量；只读不写。
   - 个股页：选股器(搜索 code/name) + 区间选择 → **三张 ECharts 并列**，各为「K 线主图 + 成交量副图」，标题标注`不复权 / 前复权 / 后复权`。文件缺失/无数据时给友好提示（不报错）。
   - 并发安全：读 Parquet 时与摄取写的冲突通过 P0 已有任务串行锁机制避免写期间读到半文件；读可接受短暂重试或直接读（列式读取）。
3. **定时调度落地**
   - 后端 APScheduler `BackgroundScheduler` 实例化，将 `cron_task` 表中 `enabled` 的任务在**应用启动时恢复注册**；`cron_expr` 为标准 cron 字段（minute hour dom month dow）。
   - 触发逻辑统一走 P0 任务执行函数（kind=ingest/strategy，`ref_id` 关联），每次触发落一条 `task_run`（复用串行锁/日志/手动终止）。
   - 增删改定时任务时同步更新调度器（新增/移除/改 Job）。
   - 前端调度页：列表（name、kind、cron、enabled、下次运行时间）、新建、编辑、启用/暂停、立即执行、删除。
   - cron 相关 API：`GET/POST /api/cron`、`PATCH /api/cron/{id}`（改 cron_expr/启停）、`DELETE /api/cron/{id}`、`POST /api/cron/{id}/trigger`（立即执行）。
4. **策略/回测**：保持 P0 能力在新前端下可用（列表/参数表单/运行/历史日志），不做深化、不加对比图表。

## 关键实现约定
- **不改 `script/`、`strategy/strategy/` 原脚本与文件**；复用 P0 摄取与任务执行逻辑，避免重复造轮。
- 主数据仍 `data/market/daily_price/*.parquet`，SQLite 只存元数据 + `stock` 映射。
- 「覆盖度」在 P1 全链路移除：前端不展示、后端不提供对应统计接口（若 P0 已有，评估后移除或标注废弃，避免误导）。
- Parquet 24 列字段名以方案 6.1 为准（`open/high/low/close` 原始价，`qfq_*` 前复权，`hfq_*` 后复权，成交量 `volume`）。
- 前端代码与注释中文；后端日志统一 UTF-8。
- 提供启动命令：后端 `uvicorn app.main:app --host 127.0.0.1 --port 8000`；前端 dev `npm run dev`；生产把 `web/dist` 交给后端托管。

## 验收标准
- `npm run build` 产物被后端托管，浏览器打开 `http://127.0.0.1:8000` 显示 Vue3 应用，五页可导航。
- 个股页选一只已摄取股票，能同时渲染「不复权/前复权/后复权」三张 K 线图+成交量，切换区间刷新；选不到数据的股票显示友好空态。
- 调度页能**新建一条"每日增量更新"cron 任务并启用**，下次运行时间计算正确，`立即执行`能触发一条 `task_run` 且可查看日志。
- **后端重启前启用任务在重启后自动恢复**（调度列表仍显示、无重启也能按 cron 触发）。
- 股票初始化后，`stock` 表有 A 股列表，选股器可按名称搜索。
- 数据管理页无覆盖度相关展示，仅最新日期/滞后天数。
